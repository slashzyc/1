# 三分钟路演与现场复现

双击 `deliverables/harborflow-roadshow.html`。左右键翻页，N 显示逐页讲稿，F 全屏；按钮启动180秒计时。讲稿的六段时长合计180秒。浏览器不支持全屏时手动进入放映即可。

## 演示前

运行 Node24 服务，确认 `/readyz`；确认模型配置。真实AI演示前执行 `node scripts/demo.mjs --live`，在“调用记录”里准备好RFQ的V3及其关联Listing、售后任务。现场网络不稳时用“离线演示模板”，必须明确说明其性质，不能把缓存或模板说成现场真实模型生成。

样例全部为合成数据，不含真实买家隐私。正式海报尺寸800×1800mm，按100%原尺寸打印，不要缩放到A4；印厂若要求出血应在外部加版，正文已有安全边距。

## 现场工作台路径（可重复）

1. 销售顾问：HF-BOX-01、德国、500件、USD3.20、FOB Ningbo、25天、14天有效。
2. 输入：“德国买家希望采购500件收纳盒，请给出报价回复，确认样品和包装要求。”点击生成。金额应为 USD1,600.00，双语草稿和规则来源均显示。
3. 打开风险与批注。欧盟资料缺失提示应存在，输出仍可导出为草稿但不能称为已批准上架。
4. 第一轮：“请更简短，保持事实与商务条件。”第二轮：“补充样品安排与跟进，不承诺未确认的交期。”检查V3与前一版对比。
5. 点击转上架。生成后展示标题、Item Highlights及英德卖点。同商品快照与源任务ID可从导出包核对。
6. 售后专员：输入“12件破损，买家要求退款”。生成后转人工，填入处理人和“核对订单、数量与照片”，状态变为处理中。
7. 可选：Listing勾选3个样例商品进行批量生成；打开规则知识库和配置导出。

## 异常应对

- 401：模型密钥无效；检查配置，不展示密钥。
- 402：模型账户余额不足；补充服务商额度或明确切换模板。
- 429／网络故障：有限重试，仍失败显示错误；再次操作前确认任务历史。
- 非法JSON：最多一次格式重试，仍失败不保存结果。
- 409：版本已更新，重新打开任务；不覆盖已有版本。
- 商品资料缺失：显示待补资料和人工处理建议，不猜测证书或责任人。

## 评委追问

“是不是纯翻译？”——不同角色有独立输入语境、任务指令和规则；RFQ是商务回复，Listing是短标题与卖点，售后是凭证收集和人工授权。

“知识库是不是联网爬的？”——运行时不爬取平台。公开资料做短篇转述与来源标记，按市场／工作流筛选，旧版本保持快照。商家数据通过授权JSON导入。

“能直接商业上线吗？”——可用作受控单工作区试点。多人商用前补齐SSO／岗位权限、监控、备份恢复演练、数据协议及行业规则维护；当前不承诺多租户生产能力。
